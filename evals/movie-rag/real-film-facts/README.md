# Real-film fact evaluation

`dataset-v1.json` freezes eighteen assistant-authored development labels across six real films, with short attributed Wikipedia production excerpts, exact source spans/revision URLs and private snapshot hashes. Excerpts avoid the evidence markers from their saved starter facts. The dataset was frozen before the first local inference and is consumed development evidence now. It is not independently annotated, held out from future tuning, or representative of every type of fact error.

`baseline-v1.json` records the unchanged qwen3.5:9b writer/critic pipeline: eighteen label matches, six useful approvals, zero of twelve flawed claims approved, zero model errors. The challenge took 102.28 seconds. Separate actual generation took 87.38 seconds, produced seven proposals across six films, and marked five drafts eligible. Approval is not publication or a correctness label.

`inspection-v1.json` binds assistant inspection to the report hash and covers all seven outputs. It records the clipped Donald H. Hewitt citation, the Knives Out memory-object wording, weak critic explanations and the supported-but-withheld Dune lighting detail. All ten saved collections and the frozen background policy are unchanged. No generated item was published.

Use `backend/scripts/evaluate_real_film_facts.py` with this dataset, the existing private `.cache/source-snapshots` directory and a **new** output path. Both stages checkpoint, retain failures in denominators, and make no automatic retries. Snapshot hash/identity/span mismatches fail before inference. The private complete snapshots are not committed; a newly fetched article revision cannot silently replace them. Source access or rebuilding the exact snapshots is required to reproduce model calls from another checkout. Contract tests use isolated source fixtures and do not call Ollama.

This isolates writer and verifier behavior with fixed excerpts; it does not exercise Chroma retrieval or embedding quality. The six-source generation inspection is separate from the live reviewed Arrival publisher registry and supplies no new generation qualification. The challenge lacks injection, missing-context and independent source-reliability coverage. Read [lesson 50](../../../docs/learning/50-real-film-fact-evaluation.md) for the differences between software tests, labelled evaluations, draft eligibility and publication.

## Complete citation fix

`complete-citations-v2.json` preserves the initial complete-name fix's full development rerun: 18/18 labelled matches, seven generated facts/five automated eligible. A deterministic replay (`complete-citation-replay-v2.json`) then exposed single-letter footnotes merging valid sentence boundaries. That intermediate helper is archived, and its report fingerprint differs from the final policy.

After fixing lettered footnotes, `complete-citations-final-generation.json` runs generation only with final fingerprints: seven proposals/five eligible, zero errors, 83.50s. It does not copy/repeat labelled scores. `complete-citation-replay-final.json` applies final boundaries to the original outputs; only the genuinely clipped Spirited Away quote is withheld. `complete-citations-comparison.json` inspects all seven final outputs: all quotes match full original source sentences, with the Spirited Away names preserved. Factual wording/critic reasoning gaps remain. These are consumed development cases; no publication or catalog-wide qualification.

The current publication fingerprint includes the helper; old background reports cannot authorize writes. The final policy's cached Arrival RAG report and separate inspection are in `../background-articles/arrival-complete-citations-*.json`. See [lesson 51](../../../docs/learning/51-complete-background-citations.md).

## Source-local names and precise paraphrases

`precision-dataset-v1.json` adds eighteen labels using **previously consumed** production excerpts: six supported controls, eight wording/qualifier distortions and four insufficient-full-name cases. Labels were frozen before this experiment's inference, but these are development cases, not fresh held-out sources. `precision-baseline-v1.json` matched 14/18 labels, accepted all six useful controls and falsely accepted two of twelve negative/missing-context cases.

Two elaborate structured-criterion reviewers overrejected: `precision-revised-v1.json` matched 6/18 (with three deadline errors and zero useful approvals); its later generation was interrupted and its top-level running state is preserved. `precision-v1-stop-inspection.json` records that stop. `precision-revised-v2-challenge.json` matched 8/18 with zero useful approvals and no errors. Their code is archived. Rejecting every supported control was grounds to abandon these approaches, not an improvement to advertise.

The third variant reused the original semantic critic with a code-owned multiword-name check. `precision-final-v3.json` matched 18/18, accepted six useful controls, withheld all twelve negatives/missing-context cases and returned four uncertain labels, without errors. Its generation revealed that the name heuristic mistook capitalized editorial headings for people, producing zero eligible drafts. That implementation is archived under `archive/precision-v3/`.

Final v4 checks factual bodies, leaves title support to the semantic critic and exempts verified registered movie titles including leading The. `precision-final-replay-v4.json` recomputes that guard on the **recorded v3 semantic judgments**: 18/18 labels still match, with zero new model calls. `precision-final-generation-v4.json` is a fresh final-policy writer/critic run across six films: seven proposals, four automated eligible, zero errors, 110.17 seconds. Every output is inspected in `precision-final-inspection.json`: three supported, one unsupported causal expansion, one verbatim copy, one likely false rejection with a flawed texture explanation, and one ambiguous remembering-them paraphrase requiring clarification. No proposal is published or automatically qualified.

The final background fingerprint includes the new helper. Publication revalidates the saved assessment and source-local names rather than trusting the report's boolean alone. `precision-preservation-after.json` verifies all ten saved collections and the story-policy hash stayed unchanged. Final cached publisher retrieval is measured separately in `../background-articles/arrival-fact-precision-v4.json`; it adds no six-film publisher coverage. See [lesson 53](../../../docs/learning/53-background-fact-precision.md) for the implementation and learning questions.
