# Private account history

Add completed quiz rounds and every successful member movie-page navigation to private account history. Guests do not record history. Movie history is enabled by default, with a Save movie-page history switch on Account; disabling stops new writes at both UI and backend, retaining existing entries until the viewer clears them. Clear each history independently through a two-step inline confirmation. History has paginated newest-first entries with film links and timestamps; quiz entries add score/scored total and round size, without revealing questions/answers in the account view.

Store history separately from collections/preferences and shared facts/quiz banks. Each client visit/round has a UUID; repeating an identical event is idempotent, conflicting reuse is rejected. Only successful movie views are tracked, not discovery tiles, failed fetches, API prefetch or feature reads. Resolve movie metadata server-side; never trust submitted titles/scores. Completed quiz submission includes a version and selected indices; server checks the saved bank/version, requires the complete round, and excludes interpretations from scoring. Save failures preserve answers and offer manual retry; replay/new generated bank rounds get new IDs. Incomplete rounds remain local UI state.

Use existing owner-from-cookie, CSRF/Origin, strict contracts, no-store boundaries. Preferences migration preserves existing rows and adds track_movie_history=true. Older preference clients omitting the new field preserve the existing value. Account history UI uses shared paper cards, left gutters, readable compact rows and dark footer; movie/quiz actions must not expose private data across accounts. Record calls are bounded JSON with no model/source generation. Pagination is live rather than frozen; refresh to see changes made elsewhere.

Tests cover owner isolation, auth/CSRF, flag-off writes, replay/id reuse, invalid films, version changes, incomplete/forged quiz inputs, interpretation scoring, clearing, newest order/pagination, reload, save-failure retry, guest nontracking and mobile layout. Use only disposable accounts and preserve all 11 shared published banks.
