# Multi-source movie evidence

Use DuckDuckGo through DDGS as the free primary discovery provider; Startpage is a configurable alternative. The adapter is replaceable. Neither provider is an availability guarantee: bounded failures, cached evidence and honest reduced coverage are mandatory. Never solve CAPTCHAs, disable TLS or cycle proxies to bypass blocks. Search only public movie identity/topic queries, not account data or raw private discussions.

Collect up to five validated full web pages for story and five for production background. Search rank is candidate ordering, not truth. Reject unsafe URLs, private IPs (including redirect targets), different-film pages, thin snippets, prompt-injection content and duplicate/syndicated pages. Require the film title plus year/director/cast identity. Pin resolved public addresses while retaining original TLS hostname and certificate verification. Fetch HTML/text only with byte/deadline budgets; preserve exact source paragraphs, URL, content hash and acquisition time. DNS/HTTP failures remain visible operational traces.

Use Wikipedia as one source alongside the web documents. Add available IMSDb screenplay context, including registered drafts and discoverable exact-title scripts. Scripts never enter facts. Drafts are labelled and cannot be the sole authority for released-film quiz answers or factual Discuss answers. Separate story/background paragraph pools; production generation uses background only, while Discuss can retrieve both. Model prompts have no arbitrary network/write actions; citations resolve only to retained source snapshots. Existing semantic-support, novelty and publication review gates remain.

Store immutable acquired source snapshots and expiring per-movie/purpose bundles in a shared corpus cache. Register only validated acquired provenance for dynamic citations. Cache misses use singleflight to avoid duplicate searches. Shared published facts/quizzes remain reusable; do not overwrite the existing 11 banks on feature installation. Research preparation and Generate more use the richer evidence; Discuss uses multi-source retrieval and support checking. Source coverage is observable, including fewer-than-five pages and script absence.

Validate provider contracts, URL/DNS/redirect safeguards, strict movie scope, duplicate rejection, purpose isolation, source provenance, cache/singleflight, failures and adversarial content with deterministic eval fixtures. Run bounded live search/source checks and a local-model answer/generation proof when available; distinguish deterministic tests from measured real-model outcomes. Document free-search availability limits and configuration, without claiming full production qualification from test counts.
